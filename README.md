# Employee Performance (offline)
Monthly behavioural & workplace performance review system. 100% offline, no cloud, no login.

- `index.html` – the whole app (open in any browser to try it)
- `main.js`, `preload.js` – Electron wrapper (PDF export, daily auto-backup, network blocked)
- Build the Windows exe: `npm install` then `npm run build` (output in `dist/`)

Employee data is stored on the user's PC (not in this repo). Use Settings → Backup Database.
